# JavVault

JavVault 是一个基于 [PythonIDE](https://www.pythonidea.cn) AppUI 运行时开发的 iOS 原生 MiniApp，由 JSBox 上的 `JavBus.js` 脚本移植而来。它提供一个简洁的原生界面，用于浏览影片列表、查看详情、播放预览与预告、管理个人收藏，全部功能单文件实现，界面尺寸按 iPhone / iPad / Mac 自动适配，无需自建服务器。

> 数据来源：[javbus.com](https://www.javbus.com)（列表与详情）、JavDB（评分）、Jable / DMM（播放链接）

## 核心功能

- **影片浏览**：首页展示最新影片封面网格，按发布时间从新到旧排列，支持下拉刷新与增量预加载
- **番号搜索**：输入番号或演员关键词即可搜索，自动规整为站点可识别的格式（如 `JUL333` → `JUL-333`）
- **女优浏览**：头像网格分页展示，点击进入该女优的作品列表
- **类型浏览**：按主题 / 角色 / 服装等一级分组查看全部二级分类，点击按分类筛选影片
- **影片详情**：封面、标题（自动翻译为中文）、发行日期、时长、发片商、制作商、系列、导演、类别、女优、样图一览
- **在线播放**：进入详情即并行预取预览 / 预告 / 完整视频三条链接，内嵌播放器自动播放，支持画中画
- **外部播放器**：可将视频链接交给 SenPlayer 等外部播放器（URL Scheme 可配置）
- **收藏管理**：详情页一键收藏（无条数上限），按收藏时间排序；收藏文件位于 MiniApp 目录内，**随 iCloud 同步**、多设备共用；缺失封面的记录会在后台自动补全
- **JavDB 评分**：详情页自动抓取并展示评分与评价人数
- **标题翻译**：详情页标题自动通过翻译接口转为中文，日文原文同时保留
- **友商跳转**：一键在 Safari 打开 JavDB / JavLibrary / Fanza / Netflav / Missav 等站点的对应搜索页
- **磁链复制**：详情页磁力链接列表，左滑即可复制
- **番号复制**：点击详情页顶部番号即复制到剪贴板

## 使用说明

| Tab | 功能 |
| --- | --- |
| 影片 | 最新影片 / 搜索结果列表，点击封面进入详情 |
| 女优 | 女优头像网格，点击查看作品 |
| 类型 | 分类按钮网格，点击按分类筛选 |
| 收藏 | 已收藏影片封面网格，长按可移除 |
| 设置 | 视频默认静音、外部播放器等配置 |

- 列表底部为翻页条：上一页 / 下一页 / 点击页码可直接跳转；
- 翻到已加载内容末尾时会自动在后台增量抓取后续页面。

### 封面网格尺寸（自适应）

- 网格按设备档位设定单列宽度的上下限：**iPhone 104~130pt / iPad 125~155pt / Mac 160~200pt**；设备类型由官方 `device` 模块判定（型号 + 屏幕特征，含 Mac 上以 iPad App 方式运行、型号与真机 iPad 相同的情形）；
- 列数由 `adaptive(minimum, maximum)` 按**实测可用宽度**自动决定：屏幕 / 窗口变宽时列数增加，单列宽度始终限制在档位区间内，网格始终铺满左右；
- 每页项数 = 列数 × 可容纳行数（按实测可用高度向下取整），因此整页始终不超出底部翻页条、**无需滚动**；旋转屏幕或缩放窗口后会重新测量并重算；
- 叠在封面上的番号 / 日期 / 女优名随档位等比缩放，与封面保持同一比例。

## 配置说明

### 应用内设置（设置 tab）

| 配置项 | 可选值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 视频默认静音 | 开 / 关 | 开 | 播放后可用系统控件开声 |
| 外部播放器 | SenPlayer | SenPlayer | 播放后可跳转外部播放器 |

> 每页项数不再提供设置项：由界面实测尺寸（列数 × 可容纳行数）自动计算，见上文「封面网格尺寸」。

### 收藏数据（`favorites.json`）

**用途**：收藏记录保存在 MiniApp 目录下的 `favorites.json` 里。应用启动时载入内存镜像，收藏 / 取消时写回文件；文件位于该目录内，因此**随 iCloud 同步**，多台设备共用同一份收藏。

| 项 | 说明 |
| --- | --- |
| 内容 | 每部一条：`code`（番号）+ `fav_time`（收藏日期），无条数上限 |
| 格式 | `{"fav": [{"code": "...", "fav_time": "YYYY-MM-DD"}, ...]}`；**列表顺序即展示顺序**（从上到下 = 从新到旧） |
| 写入 | 只在收藏变动时写入一次，且先写临时文件再原子替换，避免同步 / 中断过程中被读到半份文件 |
| 封面 | 不写进文件：收藏页封面由后台按番号补全，缓存放在临时目录，不参与同步 |

**注意事项**

- 文件顺序就是展示顺序：手工调整顺序时，把想置顶的条目往上移即可，无需其他字段；
- 多台设备**同时**收藏 / 取消可能产生 iCloud 冲突副本（如 `favorites 2.json`）：建议避免同时改动；若已出现，以内容较全的一份为准手动合并；
- 在第二台设备首次打开前，先在「文件」App 里确认 `favorites.json` 已下载到本地（尚未下载时会被视为没有收藏文件）；
- 手工编辑前建议先退出应用，避免被下一次写入覆盖。

### 运行配置（`miniapp.json`）

- `allowedNetworkHosts`：声明应用允许访问的网络域名（数据源、图片 CDN、翻译接口等），如需接入其他站点或播放器，请在此补充对应域名；
- `version`：应用版本号，设置页「关于」会读取并显示。

## 目录结构

```
JavVault/
├── main.py           # 入口与全部实现（单文件应用）
├── miniapp.json      # MiniApp 清单：名称 / 版本 / 入口 / 网络白名单
├── requirements.txt  # 第三方依赖声明（当前无第三方依赖）
├── favorites.json    # 收藏记录（随 iCloud 同步到其他设备）
├── JavBus.js         # 原始 JSBox 版脚本（移植参考）
└── README.md         # 本文件
```

`main.py` 内部按层次组织：

- **基础层**：站点常量、HTTP 封装、封面后台下载线程与磁盘缓存（LRU，上限 250 MB）
- **数据层**：设置与收藏持久化（收藏存于 `favorites.json`，随 iCloud 同步）、收藏封面后台补全
- **解析层**：列表页 / 详情页 / 播放源的 HTML 解析（预编译正则）
- **调度层**：后台线程池、详情 / 翻译 / 评分 / 播放源并行预取与主线程提交
- **展示层**：通用影片展示函数（按设备档位自适应的封面网格 + 翻页）、详情页、样图浏览
- **UI 层**：五个 tab 的视图构建与业务动作
