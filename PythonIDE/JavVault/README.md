# JavVault

JavVault 是一个基于 [PythonIDE](https://www.pythonidea.cn) AppUI 运行时开发的 iOS 原生 MiniApp，由 JSBox 上的 `JavBus.js` 脚本移植而来。它提供一个简洁的原生界面，用于浏览影片列表、查看详情、播放预览与预告、管理个人收藏，全部功能在 iPhone 上离线式单文件实现，无需自建服务器。

> 数据来源：[javbus.com](https://www.javbus.com)（列表与详情）、JavDB（评分）、Jable / DMM（播放链接）

## 核心功能

- **影片浏览**：首页展示最新影片封面网格，按发布时间从新到旧排列，支持下拉刷新与增量预加载
- **番号搜索**：输入番号或演员关键词即可搜索，自动规整为站点可识别的格式（如 `JUL333` → `JUL-333`）
- **女优浏览**：头像网格分页展示，点击进入该女优的作品列表
- **类型浏览**：按主题 / 角色 / 服装等一级分组查看全部二级分类，点击按分类筛选影片
- **影片详情**：封面、标题（自动翻译为中文）、发行日期、时长、发片商、制作商、系列、导演、类别、女优、样图一览
- **在线播放**：进入详情即并行预取预览 / 预告 / 完整视频三条链接，内嵌播放器自动播放，支持画中画
- **外部播放器**：可将视频链接交给 SenPlayer 等外部播放器（URL Scheme 可配置）
- **收藏管理**：详情页一键收藏（无条数上限），按收藏时间排序；旧收藏记录缺失的封面会在后台自动补全
- **JavDB 评分**：详情页自动抓取并展示评分与评价人数
- **标题翻译**：详情页标题自动通过翻译接口转为中文，日文原文同时保留
- **友商跳转**：一键在 Safari 打开 JavDB / JavLibrary / Fanza / Netflav / Missav 等站点的对应搜索页
- **磁链复制**：详情页磁力链接列表，左滑即可复制
- **番号复制**：点击详情页顶部番号即复制到剪贴板

## 使用说明

| Tab | 功能 |
| --- | --- |
| 影片 | 最新影片 / 搜索结果列表，点击封面进入详情 |
| 女优 | 女优头像网格，点击查看作品 |
| 类型 | 分类按钮网格，点击按分类筛选 |
| 收藏 | 已收藏影片封面网格，长按可移除 |
| 设置 | 每页项数、默认静音、外部播放器等配置 |

- 列表底部为翻页条：上一页 / 下一页 / 点击页码可直接跳转；
- 翻到已加载内容末尾时会自动在后台增量抓取后续页面。

## 配置说明

### 应用内设置（设置 tab）

| 配置项 | 可选值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 每页显示 | 6 / 9 / 12 / 15 / 18 | 9 | 对所有影片列表生效 |
| 视频默认静音 | 开 / 关 | 开 | 播放后可用系统控件开声 |
| 外部播放器 | SenPlayer | SenPlayer | 播放后可跳转外部播放器 |

### 数据文件

| 文件 | 说明 |
| --- | --- |
| `favorites.json` | 收藏记录（番号 / 封面 / 收藏时间），无条数上限 |

### 运行配置（`miniapp.json`）

- `allowedNetworkHosts`：声明应用允许访问的网络域名（数据源、图片 CDN、翻译接口等），如需接入其他站点或播放器，请在此补充对应域名；
- `version`：应用版本号，设置页「关于」会读取并显示。

## 目录结构

```
JavVault/
├── main.py           # 入口与全部实现（单文件应用）
├── miniapp.json      # MiniApp 清单：名称 / 版本 / 入口 / 网络白名单
├── requirements.txt  # 第三方依赖声明（当前无第三方依赖）
├── favorites.json    # 收藏记录持久化
├── JavBus.js         # 原始 JSBox 版脚本（移植参考）
└── README.md         # 本文件
```

`main.py` 内部按层次组织：

- **基础层**：站点常量、HTTP 封装、封面后台下载线程与磁盘缓存（LRU，上限 250 MB）
- **数据层**：设置与收藏持久化、收藏封面后台补全
- **解析层**：列表页 / 详情页 / 播放源的 HTML 解析（预编译正则）
- **调度层**：后台线程池、详情 / 翻译 / 评分 / 播放源并行预取与主线程提交
- **展示层**：通用影片展示函数（封面网格 + 翻页）、详情页、样图浏览
- **UI 层**：五个 tab 的视图构建与业务动作
